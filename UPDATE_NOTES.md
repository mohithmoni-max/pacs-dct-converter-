# DCT Workbench 4.0

- Added a Workbench for source validation, launching the PACS mapping suite, and post-generation validation.
- Added configurable date, amount, and negative-sign thresholds while preserving documented defaults.
- Added local run records with file fingerprints, settings snapshots, and explicit report-reviewed events.
- Added a virtual-environment setup launcher and a PyInstaller Windows build script.
- PACS DCT + Mapping Suite 4.0 is based on the 09-09-2026 v3.5 source.
- All-Template Validator 3.1 is based on the 17-09-2026 v3.0 source.
- Source sheets remain read-only during validation; review approval records a human review and does not modify spreadsheet values.
