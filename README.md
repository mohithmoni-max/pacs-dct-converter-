# PACS DCT Workbench

Version 4.0 combines the PACS DCT + Mapping Suite with the all-template validator in a guided Windows workflow.

## Download

[Download the DCT Workbench 4.0 release package](releases/DCT_Workbench_v4.0.zip)

The archive includes the PACS suite, DCT validator, Workbench launcher, configurable validation settings, setup instructions, and Windows build scripts.

## Main additions

- Validate input templates, open the PACS mapping suite, then validate generated output from one Workbench.
- Adjust validation tolerances from the Workbench.
- Keep a local audit history of filenames, SHA-256 fingerprints, settings, and review timestamps. Spreadsheet rows are not written into that history.
- Launch from source with `Launch_DCT_Workbench.bat`, or build standalone Windows apps with `Build_Windows_Apps.bat`.
